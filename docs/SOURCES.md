# Source repositories

This repository consolidates several earlier projects that were solving parts of the same political-media collection and analysis task.

| Source repository | Content retained here |
| --- | --- |
| `AlexArutiunian/medias-bias` | Original Wikipedia/media-source dataset and scraper |
| `AlexArutiunian/medias_bias` | Media and AllSides parsing notebooks |
| `AlexArutiunian/collect-analysis_BuildLaw` | BuildLaw collection/analysis notebook |
| `AlexArutiunian/ppl_wiki_twits` | People/Wikipedia parsing, occupation data and statistics |

The original repositories are not modified or deleted by the consolidation process.

`AlexArutiunian/wiki_med` is intended to be incorporated as well, but it must first be accessible to the connected GitHub integration.
